## Resumen ejecutivo

Se evaluó la experiencia de usuario de la plataforma Monda con **16 participantes**
(2 docentes, 14 estudiantes). Se registraron tiempos de ejecución y se aplicó el
cuestionario SUS (System Usability Scale).

### Resultados clave

| Métrica                                 | Valor          |
| --------------------------------------- | -------------- |
| Participantes totales                   | 16             |
| Docentes                                | 2              |
| Estudiantes                             | 14             |
| Alfa de Cronbach (respuestas cotejadas) | 0.8126         |
| Promedio SUS (respuestas cotejadas)     | 84.38 +/- 7.27 |
